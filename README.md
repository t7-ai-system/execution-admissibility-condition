execution-admissibility-condition

This repository contains a minimal controlled artefact set demonstrating a specific execution condition:

A divergence between prior approval and execution outcome.

---

Scope

This is not a system.
This is not a product.
This is not a full implementation.

This is a controlled demonstration of a condition.

---

Condition Observed

Two cases are presented:

Case A:
- approved = true
- authority_valid = false
- result = BLOCKED

Case B:
- approved = true
- authority_valid = true
- result = EXECUTED

---

Interpretation

These artefacts demonstrate that prior approval alone does not guarantee execution legitimacy.

Execution outcome remains dependent on authority validity at the moment of action.

---

Integrity

Each artefact includes a SHA256 hash for verification.

---

Constraint

No architecture, workflow logic, or implementation details are included.

The purpose is to expose the condition, not the system behind it.
